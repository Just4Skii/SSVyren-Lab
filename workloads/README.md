# Workloads

Workloads are controlled experiments designed to isolate specific resource behaviors.

Initial workload categories:

- CPU-only control.
- Memory-pressure control.
- Sequential storage read.
- Random storage read.
- Repeated/warm read.
- Cold-start read.
- Mixed CPU + storage.
- Mixed memory + storage.

Every workload should document what it is intended to isolate and what it cannot prove.
